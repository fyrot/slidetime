Slidetime is a lightweight browser extension designed specifically for Google Slides presentations, replacing key phrases with precise renditions of the current time. 

You can embed timers, countdowns, clocks, and dates that appear when you present with simple placeholders like "<<time>>". Try it out yourself with some of the commands below!

<<time>>              Displays the current time (hh:mm:ss pm/am)
<<date>>              Displays a shortened version of the date (mm/dd/yy)
<<mm:ss->>         Displays a countdown that goes from mm:ss to 0:00
<<mm:ss+>>        Displays a stopwatch that starts at mm:ss
<<~hh:mm>>       Displays a countdown that reaches 0:00 at hh:mm
<<shorttime>>     Displays the current time (hh:mm pm/am)
<<longtime>>       Displays the current time with millisecond precision (hh:mm:ss.SSS)
<<shortdate>>     Displays the current date (ex: Mon, Apr 14)
<<longdate>>       Displays the current date (ex: Monday, April 14, 2026)

You can extend the functionality of these placeholders by including "flags" within them. A "flag" is a type of tag that specifies additional information that determines how the extension handles the timer or clock. Information on how to add these flags to your placeholders will be updated here soon.

A version of the reference above is also available within the extension. 

All features are free.
